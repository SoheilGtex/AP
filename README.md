## How to Run
Make sure you have **Python 3.10+** installed.

To run an example:
```bash
python examples/run_example.py
```

Or run a specific file directly:
```bash
python src/exercise_02/part1_basics.py
```

## Conventions
- Each file focuses on **a single exercise or topic**.  
- Variable names are kept **simple and descriptive**.  
- Short **English comments** are added for readability.  
- Code follows the AP course’s restriction of **not using built-in helper functions** (like `max`, `min`, `sum`, etc.) when required.
